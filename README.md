## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

Day to Day workflow: 
1. Pick an issue from Github Issues
2. git checkout -b feature/your-feature
3. Build that thing/fix that bug/ clean up
4. git push origin feature/your-feature
5. Open a Pull Request on Github
6. Me or you reviews, leaves comments
7. you fix any feedback, push again
8. it gets approved
9. merge main -> auto deployed by Vercel

feature/thing-you-are-building - new features (tiktok scroll thing) 
fix/things-you-are-fixing - bug fixes 
chore/things-you-are-tidying - cleanup, refactoring
